Independent root-cause probes
-----------------------------

1. Path normalization:

  constructed = 'hardware\\kicad\\pcb\\build\\battery_pcb.kicad_pcb'
  git output  = 'hardware/kicad/pcb/build/battery_pcb.kicad_pcb'
  constructed-string membership in git output = False
  POSIX-normalized membership in git output    = True

`handoff_check.py` builds `paths` with `str(Path.relative_to(...))`, which
uses backslashes on Windows. `git ls-files` emits slash-separated paths.
The set difference therefore labels tracked files untracked.

2. Line endings after the rebuild:

  battery_pcb.kicad_pcb:
    HEAD blob: 334694 bytes, 0 CRLF, 4910 LF
    worktree:  339604 bytes, 4910 CRLF, 4910 LF

  volthium_reader.net:
    HEAD blob: 212320 bytes, 0 CRLF, 12317 LF
    worktree:  224637 bytes, 12317 CRLF, 12317 LF

The new `.gitattributes` requires `eol=lf`, but the Windows generators
write text with platform-default newline translation. `git diff --quiet`
returns 0 after the clean filter, while `git status --porcelain` reports
the generated files modified. The mandatory gate uses the latter.

3. Packet blob hashes are correct:

  volthium_reader.net  eda5076694c0eb2f78d68b41e0ef326075d088bc80f29738a1c6afa4ba9f2d8d
