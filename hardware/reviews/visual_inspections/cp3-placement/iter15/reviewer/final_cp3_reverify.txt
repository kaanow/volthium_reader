F15 severity adjudication
=========================

The fact remains accepted: git author names are free-form and not
authentication. `git log -20 --format="%h %G? %an %s"` reports `N` for every
examined commit, confirming this branch currently has no commit signatures.

The newly documented threat model is nevertheless coherent for the current
project:

- both agents act for one human principal and have full repository write;
- RPA prevents accidental scope erosion, artifact movement, missing review,
  and configuration drift;
- a deliberate actor able to spoof an author can more simply rewrite the gate,
  commit design data, or push directly;
- signed approvals therefore do not close the actual trust boundary unless
  repository permissions and credentials are separated too.

Under that explicit model, F15 is a documented limitation rather than a CP3
blocker. DR-34 preserves the correct signed-commit design if the reviewer ever
becomes a third party, credentials become segregated, or provenance must be
proved externally. The updated checker docstring now says recorded authorship,
not authentication.
