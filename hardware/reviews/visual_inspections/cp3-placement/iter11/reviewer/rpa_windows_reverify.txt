Mutable epoch-binding poison
============================

The policy calls rpa_policy_base immutable, but reviewer_patch_check.py reads
its value from SEMAPHORE.yaml at runtime. The reviewer is required to edit and
commit that file every turn. An untrailered reviewer commit that changes only
SEMAPHORE.yaml produces an empty product-code heuristic and is ignored.

The checker was imported without editing files and sem_field() was overridden
only in memory to return HEAD for rpa_policy_base. The unmodified main()
returned:

  RPA: clean - no reviewer patches in HEAD..HEAD
  MUTABLE-BASE POISON rc= 0
  reviewer semaphore-only commit code heuristic= []

Thus a routine reviewer-owned semaphore commit can move the effective epoch
past every patch without triggering the path-scope logic. The SHA identifier
is immutable, but its binding is not.
